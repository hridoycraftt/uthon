# Uthon (উঠোন)

ফ্যামিলির জন্য বানানো Mac-এর একটা মিনিমাল **সাইড ডক**। মাউস স্ক্রিনের ডান (বা বাম) কিনারায় নিলে কাঁচের মতো স্বচ্ছ একটা প্যানেল স্লাইড করে বেরিয়ে আসে। মাউস সরিয়ে নিলে আবার লুকিয়ে যায়।

> উঠোন হলো বাড়ির সেই জায়গা যেখানে সবাই একসাথে বসে। এই অ্যাপও তেমন: দরকারি সবকিছু এক জায়গায়।

## প্রথম ভার্সনে (v0.1) যা আছে

| উইজেট | কী করে |
|---|---|
| **Today** | বড় ঘড়ি, তারিখ, আর আজ ও কালকের ক্যালেন্ডার ইভেন্ট |
| **Now Playing** | Music বা Spotify-তে যে গান চলছে, সাথে play/pause/next/previous |
| **System** | CPU, মেমরি, ব্যাটারি, ডিস্কে কত জায়গা খালি |
| **Shortcuts** | অ্যাপ বা ফোল্ডারের আইকন। এক ক্লিকে খোলে। `+` চেপে বা drag করে যোগ করা যায় |
| **File Shelf** | ফাইল drag করে এখানে রেখে দাও, পরে টেনে নিয়ে যেখানে দরকার ব্যবহার করো |
| **Downloads** | Downloads ফোল্ডারের সর্বশেষ ৬টা ফাইল |
| **To-do** | ছোট একটা টু-ডু লিস্ট |
| **Care** | পানি খাওয়া আর বসার ভঙ্গির রিমাইন্ডার। আজ কয় গ্লাস পানি খেয়েছ তার হিসাবও রাখে |

আরও যা আছে:
- মেনু বারে আইকন: দেখাও, পিন করো, কোন কিনারায় থাকবে, Settings, Quit
- Settings: কিনারা বাম/ডান, সবসময় দেখাও, লগইনে চালু, প্রতিটা উইজেট দেখাও/লুকাও, রিমাইন্ডারের সময়
- লাইট আর ডার্ক মোড দুটোতেই চলে, Apple Silicon আর Intel দুই ধরনের Mac-এই চলে

## DMG কীভাবে পাবে

প্রতিবার `main` ব্রাঞ্চে push হলে GitHub Actions নিজে থেকেই অ্যাপ বিল্ড করে DMG বানায়।

- সবচেয়ে সহজ: repo-র **Releases** পেজ → সর্বশেষ রিলিজ → `Uthon-x.y.z.dmg` ডাউনলোড করো
- নতুন ভার্সন বের করতে `VERSION` ফাইলের নম্বর বাড়াও (যেমন `0.2.0`) আর push করো। নম্বর না বাড়ালে একই ভার্সনের DMG আপডেট হয়ে যায়
- প্রতিটা বিল্ডের DMG **Actions** ট্যাবের **Artifacts**-এও পাওয়া যায়

## ইনস্টল করা (ফ্যামিলির প্রতিটা Mac-এ)

1. DMG খোলো, তারপর **Uthon**-কে **Applications** ফোল্ডারে টেনে আনো
2. অ্যাপটা Apple Developer অ্যাকাউন্ট দিয়ে sign করা নেই, তাই প্রথমবার macOS খুলতে বাধা দেবে:
   - **macOS 14 (Sonoma):** Applications-এ Uthon-এর ওপর ডান-ক্লিক করো → **Open** → আবার **Open**
   - **macOS 15 (Sequoia) বা নতুন:** একবার খোলার চেষ্টা করো, তারপর **System Settings → Privacy & Security**-তে নিচে গিয়ে **Open Anyway** চাপো
   - অথবা Terminal-এ এই কমান্ডটা একবার চালাও:
     ```bash
     xattr -dr com.apple.quarantine /Applications/Uthon.app
     ```
3. মেনু বারে Uthon-এর আইকন দেখা যাবে। মাউস স্ক্রিনের ডান কিনারায় নিলে ডক বেরিয়ে আসবে

প্রথমবার ব্যবহারের সময় macOS কয়েকটা অনুমতি চাইবে: Calendar, Music/Spotify নিয়ন্ত্রণ, Downloads ফোল্ডার। যেটা দরকার সেটা Allow করো।

## নিজের Mac-এ বিল্ড করা (ঐচ্ছিক)

Xcode বা Command Line Tools লাগবে (macOS 14 বা নতুন):

```bash
./scripts/build-dmg.sh
```

DMG তৈরি হবে `dist/` ফোল্ডারে।

## প্রজেক্টের গঠন

```
Sources/Uthon/
  App/       অ্যাপ চালু হওয়া, মেনু বার, Settings
  Dock/      সাইড প্যানেল: কখন দেখাবে, কখন লুকাবে
  Stores/    ডেটা: ক্যালেন্ডার, গান, সিস্টেম, ফাইল, টু-ডু, রিমাইন্ডার
  Widgets/   প্রতিটা উইজেটের UI
  UI/        ডিজাইন: রং, কার্ড, বাটন
scripts/build-dmg.sh         .app আর .dmg বানায়
.github/workflows/build.yml  GitHub Actions অটো-বিল্ড
```

এরপর কোন কোন ফিচার যোগ হবে, তা দেখো [ROADMAP.md](ROADMAP.md)-তে।
