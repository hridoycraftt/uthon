# Uthon (উঠোন)

ফ্যামিলির জন্য বানানো Mac-এর একটা মিনিমাল অ্যাপ, দুটো জায়গা থেকে কাজ করে:

- **উপরের Island:** Dynamic Island-এর মতো, Mac-এর নচের সাথে মিশে থাকে। গান চললে বা রিমাইন্ডার এলে নচের দুই পাশে ছোট করে দেখায়। মাউস নিলে স্প্রিং অ্যানিমেশনে খুলে যায়, ভেতরে গান, ক্যালেন্ডার, শর্টকাট আর ফাইল শেলফ।
- **সাইড ডক:** মাউস স্ক্রিনের ডান (বা বাম) কিনারায় নিলে একটা প্যানেল স্লাইড করে বেরিয়ে আসে।

পুরো UI **Liquid Glass**-এ বানানো, লাইট আর ডার্ক দুই মোডেই। macOS 26-এ Apple-এর আসল Liquid Glass ব্যবহার হয়, macOS 14/15-এ কাছাকাছি দেখতে frosted glass।

> উঠোন হলো বাড়ির সেই জায়গা যেখানে সবাই একসাথে বসে। এই অ্যাপও তেমন: দরকারি সবকিছু এক জায়গায়।

## উপরের Island

**বন্ধ অবস্থায় (live activity):** গান (আর্টওয়ার্ক আর equalizer), টাইমার কাউন্টডাউন, স্টপওয়াচ, রিমাইন্ডার।

**এক ঝলকের পপ-আপ (peek):**
- ভলিউম আর ব্রাইটনেস বার। চাইলে macOS-এর নিজের পপ-আপ বন্ধ করে শুধু এটা দেখানো যায় (Accessibility অনুমতি লাগে)
- AirPods বা হেডফোন সংযুক্ত হলে L/R/Case ব্যাটারির রিং
- নতুন গান, ডাউনলোড শেষ, নতুন স্ক্রিনশট, Caps Lock
- মিটিং শুরুর ৫ মিনিট আগে **Join** বাটনসহ
- Magic Mouse/Keyboard-এর ব্যাটারি কমে গেলে সতর্কতা
- চার্জার লাগালে ব্যাটারি অ্যানিমেশন (শুধু MacBook-এ, iMac-এ নিজে থেকেই বন্ধ থাকে)
- টাইমার শেষ হলে

**খোলা Island-এর ট্যাব:** Home · Controls · Search · Shelf · Timer · Clipboard · Notes · Mirror

**জেসচার:** খোলা Island-এ স্ক্রল করলে ভলিউম বাড়ে-কমে, পাশে swipe করলে গান বদলায়। **⌃⌥Space** চাপলে যেকোনো জায়গা থেকে Island খোলে।

**iPhone-এর মতো Edit:** খোলা Island-এ **Edit** চাপো। টাইলগুলো নড়বে: লাল **−** চাপলে সরে যায়, **+ Add Widget** (পাশে সাজেশনসহ) দিয়ে যোগ হয়, টেনে এনে ক্রম বদলানো যায়। ডান-ক্লিক করলে সাইজ (ছোট/মাঝারি/বড়), রং, অন্য পেজে নেওয়া। ভুল করে সরালে **Undo**।

**Home:** ৩টা পর্যন্ত পেজ (নিচে ডট, বা পাশে সোয়াইপ)। ১৩টা উইজেট: গান, ক্যালেন্ডার, আবহাওয়া, শর্টকাট, সিস্টেম, ব্যাটারি, করণীয়, কুইক কন্ট্রোল, নোট, বুকমার্ক, বিশ্ব ঘড়ি, নামাজের সময়, বিশেষ দিন। এছাড়া Mac-এর যেকোনো অ্যাপ, আর অ্যাপের ফোল্ডার।

**থিম আর ভাষা:** ৯টা রঙের থিম, সাথে নিজের রং বেছে নেওয়া। প্রতিটা উইজেটের আলাদা রং। **বাংলা** বা ইংরেজি ইন্টারফেস। Glass নিজে থেকেই macOS অনুযায়ী বেছে নেয়।

**প্রোফাইল:** পড়াশোনা, অফিস, গান, ফ্যামিলি: এক চাপে পুরো লেআউট বদলায়। নিজের লেআউটও সেভ করে রাখা যায়, মেনু বার থেকেও বদলানো যায়।

**অন্যান্য:** Apple Reminders sync, ক্লিপবোর্ডে ছবি আর পিন, প্রতিদিন নতুন ওয়ালপেপার, অটো-আপডেট, প্রথমবার খুললে স্বাগত গাইড।

**টেস্ট:** প্রতিটা পরিবর্তনের পর GitHub Actions আসল macOS 15 আর macOS 26-এ অ্যাপটা চালায়, ১৬৮টা ফাংশনাল টেস্ট করে, আর প্রতিটা স্ক্রিনের স্ক্রিনশট `qa-macos-15` / `qa-macos-26` ব্রাঞ্চে রাখে।

**গোপনীয়তা:** কোনো অ্যাকাউন্ট বা ক্লাউড নেই, সব তথ্য এই Mac-এই থাকে। শুধু আবহাওয়ার জন্য শহরের নাম Open-Meteo-তে পাঠানো হয়।

## সাইড ডকের উইজেট (v0.1)

| উইজেট | কী করে |
|---|---|
| **Today** | বড় ঘড়ি, তারিখ, আর আজ ও কালকের ক্যালেন্ডার ইভেন্ট |
| **Now Playing** | Music বা Spotify-তে যে গান চলছে, সাথে play/pause/next/previous |
| **System** | CPU, মেমরি, ব্যাটারি, ডিস্কে কত জায়গা খালি |
| **Shortcuts** | অ্যাপ বা ফোল্ডারের আইকন। এক ক্লিকে খোলে। `+` চেপে বা drag করে যোগ করা যায় |
| **File Shelf** | ফাইল drag করে এখানে রেখে দাও, পরে টেনে নিয়ে যেখানে দরকার ব্যবহার করো |
| **Downloads** | Downloads ফোল্ডারের সর্বশেষ ৬টা ফাইল |
| **To-do** | ছোট একটা টু-ডু লিস্ট |
| **Care** | পানি খাওয়া আর বসার ভঙ্গির রিমাইন্ডার। আজ কয় গ্লাস পানি খেয়েছ তার হিসাবও রাখে |

আরও যা আছে:
- মেনু বারে আইকন: দেখাও, পিন করো, কোন কিনারায় থাকবে, Settings, Quit
- Settings: কিনারা বাম/ডান, সবসময় দেখাও, লগইনে চালু, প্রতিটা উইজেট দেখাও/লুকাও, রিমাইন্ডারের সময়
- লাইট আর ডার্ক মোড দুটোতেই চলে, Apple Silicon আর Intel দুই ধরনের Mac-এই চলে

## DMG কীভাবে পাবে

প্রতিবার `main` ব্রাঞ্চে push হলে GitHub Actions নিজে থেকেই অ্যাপ বিল্ড করে DMG বানায়।

- সবচেয়ে সহজ: repo-র **Releases** পেজ → সর্বশেষ রিলিজ → `Uthon-x.y.z.dmg` ডাউনলোড করো
- নতুন ভার্সন বের করতে `VERSION` ফাইলের নম্বর বাড়াও (যেমন `0.2.0`) আর push করো। নম্বর না বাড়ালে একই ভার্সনের DMG আপডেট হয়ে যায়
- প্রতিটা বিল্ডের DMG **Actions** ট্যাবের **Artifacts**-এও পাওয়া যায়

## ইনস্টল করা (ফ্যামিলির প্রতিটা Mac-এ)

1. DMG খোলো, তারপর **Uthon**-কে **Applications** ফোল্ডারে টেনে আনো
2. অ্যাপটা Apple Developer অ্যাকাউন্ট দিয়ে sign করা নেই, তাই প্রথমবার macOS খুলতে বাধা দেবে:
   - **macOS 14 (Sonoma):** Applications-এ Uthon-এর ওপর ডান-ক্লিক করো → **Open** → আবার **Open**
   - **macOS 15 (Sequoia) বা নতুন:** একবার খোলার চেষ্টা করো, তারপর **System Settings → Privacy & Security**-তে নিচে গিয়ে **Open Anyway** চাপো
   - অথবা Terminal-এ এই কমান্ডটা একবার চালাও:
     ```bash
     xattr -dr com.apple.quarantine /Applications/Uthon.app
     ```
3. মেনু বারে Uthon-এর আইকন দেখা যাবে। মাউস স্ক্রিনের ডান কিনারায় নিলে ডক বেরিয়ে আসবে

প্রথমবার ব্যবহারের সময় macOS কয়েকটা অনুমতি চাইবে: Calendar, Music/Spotify নিয়ন্ত্রণ, Downloads ফোল্ডার। যেটা দরকার সেটা Allow করো।

## নিজের Mac-এ বিল্ড করা (ঐচ্ছিক)

Xcode বা Command Line Tools লাগবে (macOS 14 বা নতুন):

```bash
./scripts/build-dmg.sh
```

DMG তৈরি হবে `dist/` ফোল্ডারে।

## প্রজেক্টের গঠন

```
Sources/Uthon/
  App/       অ্যাপ চালু হওয়া, মেনু বার, Settings
  Dock/      সাইড প্যানেল: কখন দেখাবে, কখন লুকাবে
  Stores/    ডেটা: ক্যালেন্ডার, গান, সিস্টেম, ফাইল, টু-ডু, রিমাইন্ডার
  Widgets/   প্রতিটা উইজেটের UI
  UI/        ডিজাইন: রং, কার্ড, বাটন
scripts/build-dmg.sh         .app আর .dmg বানায়
.github/workflows/build.yml  GitHub Actions অটো-বিল্ড
```
